### <img src="icons/code.svg" width="22" height="22" align="absmiddle" alt="" /> Ce que je fais

*Sur le projet interne de PSE Consulting :*

- **Front web** — écrans métier temps réel (planning, opérations, ventes, caisse) en React 19 / TypeScript strict, branchés sur une API Django REST typée de bout en bout via des packages partagés (`@types`, `@api-client`).
- **Mobile** — applications React Native / Expo dans le même monorepo, code et types partagés avec le web (pnpm + Turborepo).
- **Permissions & sécurité** — scoping d'accès fin (rôles, agences) côté backend et front, vérifié en conditions réelles (comptes de test par rôle, scénarios navigateur).
- **Qualité** — tests bout-en-bout Playwright, i18n (fr/en), design system interne (Ant Design + tokens), Python entièrement typé (`ty`/`ruff`).
- **Observabilité** — traçage et monitoring en production avec OpenTelemetry et Sentry.
