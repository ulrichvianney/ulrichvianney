### 🚀 Ce que je fais

- Fonctionnalités **front** React/TypeScript strict dans un monorepo pnpm + Turborepo partagé avec des apps mobiles (Expo).
- Écrans métier temps réel (planning, opérations, ventes, caisse) branchés sur une **API Django REST** typée de bout en bout via des packages partagés (`@types`, `@api-client`).
- Permissions et scoping d'accès fins (rôles, agences) côté backend et front, avec vérification systématique en conditions réelles (comptes de test par rôle, scénarios navigateur).
- Internationalisation (fr/en), design system interne (Ant Design + tokens), et discipline de typage stricte (TypeScript strict, Python entièrement typé, `ty`/`ruff`).
- Tests bout-en-bout avec Playwright pour valider chaque fonctionnalité en navigateur avant mise en production.
